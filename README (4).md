# Reliance Industries — Stock Market Analysis & Forecasting Dashboard

A Power BI report that analyzes one year of Reliance Industries Ltd. (NSE: RELIANCE) equity data — price movement, trading volume, and a forward-looking price forecast generated with an embedded Python visual.

## Data Source

Daily equity quote data exported from the **NSE (National Stock Exchange of India)** as a CSV file (`Quote-Equity-RELIANCE-EQ-10-06-2025-10-06-2026.csv`), containing 18 raw fields per trading day:

`DATE, DAY, MONTH, QUARTER, YEAR, SERIES, OPEN, HIGH, LOW, PREV. CLOSE, LTP, CLOSE, VWAP, 52W H, 52W L, VOLUME, VALUE, NO. OF TRADES`

### Data Preparation (Power Query)

- Loaded the CSV via `Csv.Document` and promoted headers.
- Typed each column explicitly:
  - Dates → `date`
  - Price fields → `number`
  - `VOLUME` / `NO. OF TRADES` → whole number
- Removed unused columns to keep the model lean.
- Built **Day / Month / Quarter / Year** date attributes to drive the report's time-based slicers.

## Forecasting Model

The forecast on Page 2 is generated by a Python script embedded directly in the Power BI visual using `dataset`, Power BI's built-in Python visual data frame.

The model implements a **Dampened Holt's Linear Trend** time-series forecasting approach.

### 1. Load & Clean

The Python script:

- Pulls `DATE` and `CLOSE` from the Power BI filter context.
- Parses the date column.
- Removes duplicate records.
- Removes null values.
- Sorts the data chronologically.

### 2. Fit the Model

The model smooths:

- **Price level** using `alpha = 0.25`
- **Trend** using `beta = 0.08`

### 3. Dampen & Project

A damping factor of:

```text
phi = 0.95
```

is applied to prevent the trend from extrapolating linearly forever.

The model then projects the stock price **360 business days into the future**.

### 4. Forecast Milestones

The forecast includes milestone markers at:

- **30 days**
- **90 days**
- **180 days**
- **360 days**

Each marker displays the corresponding projected price.

### 5. Visualization

The final visualization is generated using **Matplotlib** and displays:

- Historical closing price as a solid line
- Forecasted price as a dashed line
- Forecast milestone markers

The resulting visualization is rendered directly inside the Power BI report.

> **Note:** This model is a statistical trend projection for illustrative and analytical purposes only. It does not account for news, earnings, corporate actions, macroeconomic conditions, or market sentiment and should not be considered financial advice.

## How to Use

### 1. Open the Power BI Report

Open:

```text
reliance.pbix
```

using **Power BI Desktop**.

Power BI Desktop 2023+ is recommended for Python visual support.

### 2. Configure Python

Ensure Python is installed with the following packages:

```text
pandas
numpy
matplotlib
```

Configure the Python environment under:

**File → Options and settings → Options → Python scripting**

### 3. Explore Page 1

Use the following slicers to filter the dashboard:

- Day
- Month
- Quarter
- Year

The KPI cards and charts will dynamically respond to the selected filters.

### 4. Explore Page 2

Navigate to the **Forecast** page to view the 360-business-day forecast.

The date slicer can be used to adjust the historical data window that feeds the forecasting model.

### 5. Refresh the Data

To update the dashboard with new data:

1. Replace the source CSV file.
2. Open **Power Query**.
3. Go to **Data Source Settings**.
4. Update the source path if required.
5. Click **Refresh**.
