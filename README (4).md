# Reliance Industries — Stock Market Analysis & Forecasting Dashboard

A Power BI report that analyzes one year of Reliance Industries Ltd. (NSE: RELIANCE) equity data — price movement, trading volume, and a forward-looking price forecast generated with an embedded Python visual.

| **Data period** | 10 Jun 2025 – 10 Jun 2026 (247 trading days) |
| **Pages** | 2 |
| **Tools** | Power BI Desktop, Power Query, DAX, Python (pandas, numpy, matplotlib) |

## Data Source

Daily equity quote data exported from the **NSE (National Stock Exchange of India)** as a CSV file (`Quote-Equity-RELIANCE-EQ-10-06-2025-10-06-2026.csv`), containing 18 raw fields per trading day:

`DATE, DAY, MONTH, QUARTER, YEAR, SERIES, OPEN, HIGH, LOW, PREV. CLOSE, LTP, CLOSE, VWAP, 52W H, 52W L, VOLUME, VALUE, NO. OF TRADES`

### Data preparation (Power Query)
- Loaded the CSV via `Csv.Document` and promoted headers.
- Typed each column explicitly (dates → `date`, price fields → `number`, `VOLUME`/`NO. OF TRADES` → whole number).
- Removed unused columns to keep the model lean.
- Built out **Day / Month / Quarter / Year** date attributes to drive the report's time-based slicers.

## Forecasting Model

The forecast on Page 2 is generated by a Python script embedded directly in the Power BI visual (via `dataset`, Power BI's built-in Python visual data frame). It implements a **dampened Holt's Linear Trend** time-series model:

1. **Load & clean** — pulls `DATE` and `CLOSE` from the report's filter context, parses dates, drops duplicates/nulls, and sorts chronologically.
2. **Fit** — smooths the price *level* (`alpha = 0.25`) and *trend* (`beta = 0.08`) over the historical series.
3. **Dampen & project** — applies a damping factor (`phi = 0.95`) so the trend flattens rather than extrapolating linearly forever, then projects **360 business days** forward.
4. **Milestone markers** — annotates the forecast line at the **30-day, 90-day, 180-day, and 360-day** horizons with the projected price.
5. **Render** — plots historical close price (solid line) against the stabilized forecast (dashed line) using `matplotlib`, returned to the Power BI canvas.

> **Note:** This model is a statistical trend projection for illustrative/analytical purposes only — it does not account for news, earnings, corporate actions, or market sentiment, and should not be used as financial advice.

## How to Use

1. Open `reliance.pbix` in **Power BI Desktop** (2023+ recommended for Python visual support).
2. Ensure a Python environment with `pandas`, `numpy`, and `matplotlib` is configured under **File → Options and settings → Options → Python scripting**.
3. Use the slicers on Page 1 to filter by day, month, quarter, or year.
4. Visit Page 2 to view the 360-day price forecast; use the slicer to adjust the historical window feeding the model.
5. To refresh with new data, replace the source CSV path in **Power Query → Data Source Settings** and click **Refresh**.
